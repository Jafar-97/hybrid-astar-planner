Hybrid A* Motion Planner — Live Demo

A car-like vehicle plans a kinematically feasible path through a costmap with Hybrid A* (dual Dubins + Dijkstra heuristic, analytic Dubins goal expansion), then tracks it with a pure-pursuit + PID controller on a bicycle-model simulation — all running live in your browser. Draw obstacles, move the goal, and hit Plan & Drive.

This runs a faithful JavaScript port of the C++ implementation in this repo (same bicycle model, heuristics, Dubins math, and controller).
